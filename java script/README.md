# Painel Interativo de Cursos

Atividade de *Linguagens de Script para a Web* (IFPB) para praticar manipulação do DOM com JavaScript puro.

*Funciona assim:* filtra cursos por nome e área, mostra/oculta detalhes, cadastra e remove cursos, e exibe mensagens de sucesso ou erro.

*Conceitos:* eventos, bubbling, delegação de eventos, classList e createElement.

*Tecnologias:* HTML, CSS e JavaScript.

*Executar:* abra o index.html no navegador.
